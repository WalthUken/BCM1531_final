# BCM 1531, examen final

Animations pour réviser l'examen final de BCM 1531 (Introduction à la biochimie, Université de Montréal, automne 2026).

**Site : https://walthuken.github.io/BCM1531_final/**

## Contenu

- **Glucides : structure (cours synchrone 4)** : hiérarchie des polysaccharides
- **Métabolisme : généralités (cours 5.1)** : absorption intestinale du glucose, GLUT et insuline, catabolisme et anabolisme des glucides, cycles du citrate, des pentoses et du glyoxylate
- **Glucides : métabolisme (cours 5.2)** : fructose, galactose, zoom sur la galactose-1-P uridyltransférase, mannose
- **Glucides : glycolyse (cours synchrone 5)** : les 10 enzymes de la glycolyse sur les vraies structures, avec un mode révision

Contenu tiré du plan de cours et des diapositives du cours. Outil de révision personnel.
